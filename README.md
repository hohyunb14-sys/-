# 방호현 에이전시 — 오피스 맵

내 삶을 방(Room) 단위로 나누고, 이름과 역할이 있는 직원 캐릭터들이 서로 찾아가
이야기하고 회의하며 결과물을 쌓아가는 모습을 게임 화면처럼 보여주는 시각화입니다.

`office-map.html` 파일 하나. 브라우저로 열면 바로 돕니다. 설치·빌드 없음.

```bash
open office-map.html
```

## 등장인물

| | 이름 | 역할 | 자리 |
|---|---|---|---|
| 🟫 | 대표 | 지시를 내림 | 대표실 |
| 🟧 | 비서 | 지시를 받아 각 방에 하달 | 대표실 → 전 층 |
| 🟥 | 서진 | 콘텐츠 작가 | 장례 콘텐츠실 |
| 🟩 | 한결 | 건강 코치 | 건강관리실 |
| 🟪 | 다온 | 채널 PD | 자기계발 채널실 |

## 평면도

```
  장례 콘텐츠실 ────┐         ┌──── 건강관리실
                   └─ 복도 ─┘
                      대표실
                   ┌─ 복도 ─┐
  자기계발 채널실 ──┘         └──── 회의실
```

## 돌아가는 방식

1. **지시** — 대표가 지시하면 비서가 담당 직원을 찾아가 하달합니다
2. **작업** — 직원이 자리에서 작업하고, 끝나면 그 방 서가에 결과물이 쌓입니다
   (자리를 비우면 작업도 멈춥니다)
3. **복도 대화** — 직원끼리 서로 찾아가 짧게 대화합니다
4. **회의** — `회의 소집`을 누르면 전원이 회의실에 모여 순서대로 발언하고, 회의록과
   후속 과제가 남습니다
5. **시너지** — 두 방 이상의 재료가 모이면 해당 부서가 열리고, 그 방 직원들만 모여
   합작 산출물을 만듭니다

## 부서 (방끼리 붙여 만드는 시너지)

| 부서 | 방 조합 | 산출물 |
|---|---|---|
| 콘텐츠 제작국 | 장례 콘텐츠실 + 자기계발 채널실 | 영상 패키지 |
| 자기관리국 | 건강관리실 + 자기계발 채널실 | 성장 리포트 |
| 전략실 | 세 방 전부 | 주간 전략 |

## 방 클릭 → 콘텐츠 연관도

방을 클릭하면 그 방의 결과물이 노드 그래프로 열립니다.
결과물마다 태그(`#대본` `#촬영` `#체중` …)가 붙어 있고,

- **실선** — 같은 방 안에서 태그가 겹치는 결과물끼리
- **점선** — 다른 방에 있는 관련 결과물 (이게 부서 시너지의 근거가 됩니다)

옆 패널에 결과물 목록, 많이 쓰인 태그, 소속 부서가 함께 나옵니다.
