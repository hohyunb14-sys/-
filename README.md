# voicecut

내 목소리 녹음(또는 강의 영상)을 넣으면 **무음, 간투어("음", "어"), 다시 말한 구간**을 자동으로 찾아 주고,
브라우저에서 하나씩 들어 보며 확인한 뒤 잘라낸 파일을 만들어 주는 개인용 도구입니다.

- 원본은 건드리지 않고 새 파일을 만듭니다.
- 인터넷 없이도 동작하지만(로컬 Whisper), 한국어는 리턴제로 STT 키를 넣는 편이 훨씬 정확합니다.
- AI 검토(Claude)는 선택 사항입니다. 켜면 전사문(텍스트)만 보내고 음성은 보내지 않습니다.

## 어떻게 동작하나

1. 파일에서 오디오를 뽑아 무음 구간을 잽니다 (ffmpeg).
2. 음성 인식으로 단어별 시간이 붙은 전사문을 만듭니다. 이때 간투어를 지우지 않고 그대로 받아씁니다.
3. 규칙으로 컷 후보를 찾습니다.
   - **무음**: 정한 길이 이상의 멈춤을 짧게 줄임 (기본 0.6초 이상 → 0.3초)
   - **간투어**: "음", "어", "으", "아" 등. "그", "저", "뭐"는 뒤에 멈춤이 있을 때만
   - **마커**: 말이 꼬였을 때 "다시"라고 말하고 다시 말했으면, "다시" 앞의 잘못 말한 시도를 삭제
   - **반복**: 마커 없이 같은 문장을 다시 말한 경우 앞 시도를 삭제 (유사도 기준)
4. (선택) Claude가 전사문을 읽고 규칙이 놓친 말실수를 제안하고, 규칙이 잘못 잡은 것을 표시합니다.
5. 브라우저에서 컷마다 들어 보고 체크를 조정한 뒤 **내보내기**를 누르면 새 파일이 만들어집니다.

## 설치와 실행

Python 3.10 이상이 필요합니다 ([python.org](https://www.python.org/downloads/)에서 설치, Windows는 "Add python.exe to PATH" 체크).

- **Windows**: `run.bat` 을 더블클릭
- **macOS / Linux**: 터미널에서 `./run.sh`

처음 실행할 때 필요한 패키지를 내려받느라 몇 분 걸립니다. 끝나면 브라우저에 `http://127.0.0.1:8765/` 가 열립니다.
ffmpeg는 따로 설치하지 않아도 됩니다 (패키지에 포함된 실행 파일을 씁니다).

직접 설치하려면:

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -e ".[ai]"           # AI 검토까지. Whisper도 쓰려면 ".[ai,whisper]"
voicecut serve
```

## 음성 인식 고르기

| 방식 | 장점 | 단점 |
|---|---|---|
| **리턴제로 (추천)** | 한국어 정확도 높음, 간투어를 살려서 받아씀, 내 컴퓨터가 느려도 됨 | 인터넷 필요, 음성이 리턴제로 서버로 감, API 키 필요 |
| **Whisper (로컬)** | 인터넷·키 없이 동작 | GPU 없으면 매우 느림, 간투어를 자주 빼먹음, 모델 첫 다운로드 수 GB |

리턴제로 키는 [developers.rtzr.ai](https://developers.rtzr.ai/)에서 무료로 발급받아 **설정** 화면(우측 상단)에 client_id / client_secret을 넣으면 됩니다.
Whisper를 쓰려면 `pip install faster-whisper` 를 실행하세요. 설정의 "기본 음성 인식"이 "자동"이면 키가 있을 때 리턴제로, 없으면 Whisper를 씁니다.

## 검토 화면 사용법

- 왼쪽은 대본, 오른쪽은 컷 목록입니다. 대본에서 색이 칠해진 단어가 잘릴 부분이고, 점선 밑줄은 제안됐지만 체크가 풀린 부분입니다.
- 컷마다 **▶ 앞뒤 포함**(잘린 결과를 앞뒤 1.5초와 함께 듣기), **▶ 잘릴 부분**(지워질 소리만 듣기) 버튼이 있습니다.
- 체크박스를 끄면 그 컷은 적용하지 않습니다. 오른쪽 위 필터로 종류별로 숨기거나 한 번에 선택/해제할 수 있습니다.
- **직접 잘라내기**: 대본에서 시작 단어를 클릭하고 끝 단어를 클릭하면 그 구간이 "직접" 컷으로 추가됩니다.
- **찾기** 칸에 단어를 넣고 Enter를 누르면 대본에서 찾아 그 위치로 이동합니다.
- 상단 **편집본 미리듣기**를 켜면 체크된 컷을 건너뛰며 재생됩니다. 스페이스바로 재생/정지.
- **탐지 기준 조정**에서 무음 길이나 마커 단어를 바꾸고 "다시 분석"을 누르면 전사는 다시 하지 않고 컷만 다시 찾습니다. 직접 추가한 컷과 이미 정한 선택은 유지됩니다.
- **내보내기**를 누르면 결과 파일이 만들어지고 다운로드 링크가 뜹니다. 영상은 mp4(H.264/AAC), 음성은 원본과 같은 형식으로 나옵니다. 영상에서 오디오만 뽑을 수도 있습니다.
- "정리된 대본(txt) 받기"로 잘라낸 뒤의 대본을 받을 수 있습니다.

## 녹음할 때 한 가지 습관: "다시"

가장 정확하게 잡히는 방식입니다. 말이 꼬이면

1. 잠깐 멈추고
2. **"다시"** 라고 또렷하게 말한 뒤
3. 다시 잠깐 멈추고
4. 그 문장을 **처음부터** 다시 말합니다.

도구가 "다시" 앞뒤 문장을 대조해서 앞의 잘못된 시도를 통째로 잘라냅니다. "다시 한번 정리하면"처럼 말이 이어지는 경우는 마커로 보지 않으므로 평소 말투에서 "다시"를 써도 괜찮습니다.
마커 단어는 설정에서 바꿀 수 있습니다 (예: "컷", "엔지").

## AI 검토 (선택)

설정에 Anthropic API 키를 넣고 `pip install anthropic` 이 되어 있으면, 작업을 만들 때 "AI 검토도 함께 실행"을 켜거나 검토 화면의 "AI 검토 실행" 버튼을 누를 수 있습니다.

- 보내는 것: 발화 번호와 시간이 붙은 전사문, 규칙이 찾은 컷 목록. **음성 파일은 보내지 않습니다.**
- 하는 일: 규칙이 놓친 말실수·다시 말한 구간·버려진 문장을 제안하고, 규칙 컷 중 정상 발화로 보이는 것을 표시해 체크를 풀어 둡니다.
- 기본 모델은 `claude-opus-5` 이고, 거절 응답이 나오면 서버가 자동으로 다른 Claude 모델로 이어 처리하도록 설정되어 있습니다.
- AI 제안은 신뢰도가 높은 것만 기본 체크됩니다. 1시간 녹음 기준 비용은 몇백 원 수준입니다.

## 명령줄로 쓰기

```bash
voicecut process 녹음.mp4                 # 분석만 하고 작업 폴더에 저장 (검토는 브라우저에서)
voicecut process 녹음.mp4 --apply         # 기본 선택된 컷을 바로 적용해 결과 파일까지 생성
voicecut process 녹음.mp4 --ai --apply --audio-only
voicecut serve --port 9000 --no-open      # 다른 포트, 브라우저 자동 열기 끔
```

## 기대할 수 있는 정확도와 한계

| 기능 | 기대치 | 메모 |
|---|---|---|
| 무음 줄이기 | 매우 높음 | 배경 소음이 크면 무음 기준(dB)을 낮추세요 |
| 간투어 | 리턴제로: 높음 / Whisper: 낮음 | STT가 간투어를 받아써야 잡힙니다 |
| "다시" 마커 | 높음 | 마커 앞뒤로 잠깐 멈추는 게 핵심 |
| 마커 없는 반복 | 보통 | 거의 같은 문장을 반복했을 때만. 다르게 다시 말하면 놓침 |
| 틀렸는데 다시 말하지 않은 부분 | 자동 불가 | 찾기 기능으로 직접 잘라내거나 AI 검토를 써 보세요 |

이 수치는 아직 실제 녹음으로 잰 것이 아닙니다. 본인 녹음 두세 개로 돌려 보고 "탐지 기준 조정"으로 맞춰 가는 것을 권합니다.

## 작업 폴더와 개인정보

- 작업은 `voicecut_jobs/<작업id>/` 에 저장됩니다: 원본 복사본(업로드한 경우), 분석용 wav, 미리듣기 mp3, 전사(`transcript.json`), 컷(`cuts.json`), 결과 파일.
- 경로를 직접 입력한 파일은 복사하지 않고 그 자리에서 읽습니다.
- API 키는 `voicecut_jobs/settings.json` 에 평문으로 저장됩니다. 내 컴퓨터에서만 쓰는 도구라는 전제입니다. 환경변수 `RTZR_CLIENT_ID`, `RTZR_CLIENT_SECRET`, `ANTHROPIC_API_KEY` 가 있으면 그 값을 우선합니다.
- 서버는 127.0.0.1 에서만 열리므로 다른 컴퓨터에서는 접속할 수 없습니다.

## 문제가 생기면

- **ffmpeg를 찾을 수 없다**: `pip install imageio-ffmpeg` 를 다시 실행하거나, 환경변수 `VOICECUT_FFMPEG` 에 ffmpeg 경로를 넣으세요.
- **Whisper가 너무 느리다**: 설정의 Whisper 모델을 `medium` 이나 `small` 로 바꾸거나, 리턴제로 키를 쓰세요.
- **리턴제로 응답 형식이 바뀌어 단어 시간이 이상하다**: `voicecut/transcribe/rtzr.py` 의 `parse_rtzr_result` 가 응답을 읽는 부분입니다. 공개 문서 기준으로 작성했고 필드 이름이 달라도 최대한 읽도록 했지만, 실제 키로 한 번 확인이 필요합니다.
- **포트가 이미 사용 중**: `voicecut serve --port 9000`
