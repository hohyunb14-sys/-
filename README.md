# 방호현 에이전시 — 오피스 맵

내 삶을 방(Room) 단위로 나누고, 직급과 성향을 가진 직원 캐릭터들이 지시를 주고받고
조율하고 회의하며 결과물을 쌓아가는 모습을 게임 화면처럼 보여주는 시각화입니다.

`office-map.html` 파일 하나. 브라우저로 열면 바로 돕니다. 설치·빌드 없음.

```bash
open office-map.html
```

> **이 파일은 맥의 파일을 읽거나 쓰거나 지우지 않습니다.**
> 브라우저 안에서만 도는 데모이고, `~/agency/` 카운트는 화면 안에서 세는 숫자입니다.
> `초기화` 버튼도 화면 상태만 되돌립니다.

## 조직도

```
대표
└ 비서 (에이전트 비서)
   ├ 장례 콘텐츠실 — 서진 실장 / (과장) / (대리)
   ├ 건강관리실   — 한결 실장
   └ 자기계발 채널실 — 다온 실장
```

- 지시는 **위에서 아래로만** 흐릅니다. 비서는 항상 **실장**에게만 하달합니다.
- 실장은 아래가 비어 있으면 **위임**하고, 아무도 없으면 직접 합니다.
- 방마다 자리 3개 (실장 / 과장 / 대리).

## 방마다 고유한 성향

협업이 들어와도 이 선은 지킵니다.

| 방 | 원칙 | 안 하는 것 |
|---|---|---|
| 장례 콘텐츠실 | "정보보다 태도" — 유가족이 지금 당장 쓸 수 있는 말만 남긴다 | 자극적인 제목, 통계 나열, 과장된 감정 연출 |
| 건강관리실 | "기록이 먼저" — 의욕이 아니라 숫자로 말한다 | 무리한 목표, 남과 비교, 정신력 타령 |
| 자기계발 채널실 | "오늘 하나" — 오늘 실제로 한 것 하나를 보여준다 | 성공 서사, 안 한 걸 한 척 |

## 파생 — 실제로 작동하는 브레인스토밍

1. 방을 클릭하면 그 방의 결과물이 노드 그래프로 열립니다
2. **동그라미를 클릭**하면 "여기서 파생할 수 있는 일" 목록이 나옵니다
3. 누르면 **실제로 지시가 나갑니다** — 직원이 작업하고 새 결과물이 생깁니다
4. 새 결과물은 부모와 **굵은 화살표**로 이어집니다 (실제 파생 계보)

선의 의미:

- **굵은 화살표** — 실제 파생 계보 (A에서 B가 나왔다)
- **가는 실선** — 태그가 겹치는 결과물
- **점선** — 다른 방에 있는 관련 결과물

## 조율 — 다른 방 일이면 반드시 협의한다

파생이 다른 방 소관이면, 두 방의 **실장이 회의실에서 먼저 조율**합니다.

```
비서: 장례 콘텐츠실 → 자기계발 채널실 협업 건입니다.
서진: "대본 초안"에서 나온 겁니다. 숏폼 3컷 요약 부탁드립니다.
다온: 받겠습니다. 저희 원칙은 "오늘 하나" — 거창한 성장 대신…
서진: 저희는 자극적인 제목은 안 됩니다. 그 선만 지켜주세요.
다온: 자극적인 제목 빼고, "오늘 하나" 기준으로 만들겠습니다.
비서: 양쪽 원칙 다 붙여서 남기겠습니다.
```

합의된 원칙은 결과물에 **조율된 원칙**으로 붙어서 남습니다.

## 부서 (방끼리 붙여 만드는 시너지)

| 부서 | 방 조합 | 산출물 |
|---|---|---|
| 콘텐츠 제작국 | 장례 콘텐츠실 + 자기계발 채널실 | 영상 패키지 |
| 자기관리국 | 건강관리실 + 자기계발 채널실 | 성장 리포트 |
| 전략실 | 세 방 전부 | 주간 전략 |

## 직접 조작

| 조작 | 위치 |
|---|---|
| **아무 말이나 지시** | 화면 아래 입력창. 자동으로 담당 방을 찾습니다 |
| **직원 추가** | TEAM 카드 → `+ 직원 추가`. 이름·역할·방(또는 새 방 + 원칙) |
| **회의 소집** | 전원이 회의실에 모입니다 |
| **근무일 / 휴무일** | 조명·속도·브리핑 문구가 바뀝니다 |
| **초기화** | 화면 상태만 되돌립니다 (맥 파일은 그대로) |

추가한 직원과 방은 이 브라우저에 기억됩니다 (localStorage).

## 토큰 사용량

우상단 HUD와 TOKENS 카드에서 사람별로 봅니다.
**지금은 추정치**입니다 — 실제 사용량을 붙이면 같은 자리에 그대로 들어갑니다.

## 아직 안 한 것

1. **데일리 브리핑 화면** — 영상 촬영용
2. **진짜 데이터 연결** — `~/agency/` 폴더를 실제로 읽기
3. **실제 토큰 사용량 연결** (`~/.claude/projects/*.jsonl`)
4. **근무/휴무 자동 판단**
5. 새로 만든 방은 아직 부서에 자동으로 들어가지 않습니다
