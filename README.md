# 방호현 에이전시 — 오피스 맵

내 삶을 방(Room) 단위로 나누고, 비서 캐릭터가 지시를 받아 각 방에 하달하고
결과물을 서가에 정리하는 모습을 게임 화면처럼 보여주는 시각화 시안입니다.

## 지금 있는 것

- `office-map.html` — 단일 파일. 브라우저로 열면 바로 돕니다. (설치·빌드 없음)

### 화면 구성

| 영역 | 내용 |
|---|---|
| 오피스 맵 | 대표실(가운데) + 방 3개. 비서가 복도를 걸어 지시를 전달하고 돌아옵니다 |
| 지시 내리기 | 프리셋 버튼. 누르면 대표가 지시 → 비서가 이동 → 직원이 작업 → 서가에 결과물 |
| TODAY | 근무일 / 휴무일 모드. 조명·작업 속도·브리핑 문구가 함께 바뀝니다 |
| ROOMS | 방별 상태, 쌓인 결과물 수, 최근 생성 파일 |
| ACTIVITY | 활동 로그 |
| ~/agency/ | 폴더 거울 — 방에 물건이 쌓이면 여기에 파일이 하나 생깁니다 |

### 방 3개

- `rooms/funeral-content` — 장례 콘텐츠실 (유튜브 기획·대본·PD 인터뷰)
- `rooms/health` — 건강관리실 (운동 시간, 체중 추적)
- `rooms/channel` — 자기계발 채널실 (브리핑 영상, 사진 연습 과제)

## 맥에서 보기

```bash
open office-map.html
```
