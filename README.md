# 방호현 에이전시

내 삶을 방(Room) 단위로 나눠 폴더에 담고, 그 폴더를 게임 화면처럼 보여주는 시스템.

```
~/agency/          ← 진짜 자료가 사는 곳 (Claude Code 가 여기서 일함)
     ↓  node scan.mjs   (읽기만 함)
  state.js
     ↓
office-map.html    ← 그 폴더를 비추는 화면
```

## 맥에서 설치 (3분)

```bash
git clone https://github.com/hohyunb14-sys/- agency-app
cd agency-app
git checkout claude/animated-room-management-a8hlc4

./install.sh          # ~/agency 를 만듭니다
node scan.mjs         # 폴더를 읽어 화면에 반영
open office-map.html  # 화면 열기
```

그 다음부터 실제 작업은 이렇게:

```bash
cd ~/agency && claude
```

## 안전 (제일 중요)

| | |
|---|---|
| `install.sh` | 이미 있는 파일은 **덮어쓰지 않습니다** (`cp -Rn`) |
| `scan.mjs` | **읽기 전용.** 쓰는 파일은 `state.js` 하나뿐 |
| `office-map.html` | 브라우저 안에서만 돕니다. 맥 파일에 접근 권한이 없습니다 |
| `초기화` 버튼 | **화면 상태만** 되돌립니다 |
| `~/agency/CLAUDE.md` | "지우지 않는다"가 1번 규칙으로 박혀 있습니다 |

어디에도 삭제 기능이 없습니다.

## ~/agency 구조

```
~/agency/
├─ CLAUDE.md              전체 규칙 — Claude Code 가 제일 먼저 읽음
├─ team.md                조직도 (이름 | 직급 | 역할 | 방)
├─ rooms/
│  ├─ funeral-content/
│  │  ├─ CLAUDE.md        이 방의 원칙과 "안 하는 것"
│  │  └─ 2026-08-25_수의-선택-가이드.md
│  ├─ health/  (+ health.csv)
│  └─ channel/
├─ meetings/              회의록
├─ depts/                 부서 시너지 산출물
└─ daily/                 날짜별 브리핑 (근무일/휴무일 표시)
```

### 방마다 CLAUDE.md — 이게 핵심입니다

```md
# 장례 콘텐츠실

- 모토: 정보보다 태도
- 원칙: 유가족이 지금 당장 쓸 수 있는 말만 남긴다.
- 안 하는 것: 자극적인 제목, 통계 나열, 과장된 감정 연출
- 말투: 담담하고 낮은 톤
- 색: #E0A458
```

- **Claude Code** 가 그 방에서 일할 때 자동으로 읽습니다 → 그 방 성향대로 씁니다
- **scan.mjs** 가 같은 파일을 읽어 화면의 방 이름·색·원칙을 채웁니다

사람도 방도 **마크다운만 고치면** 화면이 따라옵니다. `team.md` 표에 한 줄 추가하고
`node scan.mjs` 를 다시 돌리면 새 직원이 화면에 나타납니다.

### 결과물 파일 앞머리

```
---
결과물: 대본 초안
태그: 대본, 장례, 촬영
작성: 서진 실장
출처: 2026-08-25_수의-선택-가이드.md
원칙: 자극적인 제목 제외
---
```

`출처`가 화면의 **파생 화살표**가 되고, `원칙`이 **조율된 원칙**으로 표시됩니다.

## 화면에서 할 수 있는 것

| 조작 | 결과 |
|---|---|
| **방 클릭** | 그 방 결과물의 연관도 |
| **동그라미 클릭** | 여기서 파생할 수 있는 일 목록 |
| **파생 누르기** | 다른 방 일이면 두 실장이 조율 → **붙여넣을 프롬프트** 생성 |
| **지시 입력** | 자유 텍스트 → 담당 방 자동 배정 → 프롬프트 생성 |
| **회의 소집** | 전원이 회의실로 |
| **직원 추가** | 이름·직급·역할·방 (또는 새 방 + 원칙) |
| **초기화** | 화면 상태만 되돌림 |

### 프롬프트 다리

화면에서 지시를 내리면 **그 방의 원칙과 조율 결과가 이미 들어간 프롬프트**가 나옵니다.
복사해서 `cd ~/agency && claude` 에 붙여넣으면 실제 파일이 만들어집니다.

```
(~/agency 에서 claude 를 켠 상태 기준)

rooms/channel/ 에서 작업해줘.

할 일: 수의 선택 가이드 → 숏폼 3컷 요약
출처 파일: 2026-08-25_수의-선택-가이드.md

이 방 원칙 (rooms/channel/CLAUDE.md):
- "오늘 하나" — 거창한 성장 대신 오늘 실제로 한 것 하나를 보여준다.
- 안 하는 것: 성공 서사, 안 한 걸 한 척

다른 방과 조율한 것:
- 장례 콘텐츠실: 자극적인 제목 제외
- 자기계발 채널실: 오늘 하나 유지

결과는 rooms/channel/2026-08-25_제목.md 로 새로 만들고 ...
기존 파일은 지우거나 고치지 말아줘.
```

즉 **화면은 보는 곳이자 지시를 짜는 곳이고, 파일을 만드는 건 Claude Code** 입니다.

## 토큰 사용량

`~/.claude/projects/*.jsonl` 을 읽어 **실측치**를 표시합니다 (오늘 / 누적 / 프로젝트별).
로그를 못 찾으면 추정치 모드로 떨어지고 그렇게 표시합니다.

## 두 가지 모드

- `state.js` 가 있으면 **실데이터 모드** — 좌상단에 초록 배지, 프리셋 버튼 숨김, 자동 진행 끔
- 없으면 **데모 모드** — 가상의 직원과 결과물로 구조만 보여줌

## 갱신

폴더를 고친 뒤 `node scan.mjs` 를 다시 돌리고 화면을 새로고침하면 됩니다.

```bash
# 30초마다 자동 갱신하고 싶으면
while true; do node scan.mjs >/dev/null; sleep 30; done
```

## 인생샷 처방전 (`photo-guide.html`)

사진 찍을 때 **뭐가 불편한지 찾아서, 원인을 하나씩 고쳐 나가게** 돕는 앱.
유튜브 규민 JAYQ 「인생샷 찍는 방법」 영상의 원칙을 고민별로 다시 묶었다.

```bash
open photo-guide.html   # 폰에서 쓰려면 claude.ai 아티팩트 링크로 연다
```

| 탭 | 하는 일 |
|---|---|
| **고민 찾기** | "다리가 짧아 보여요" 같은 고민 21개 → 원인을 흔한 순서로 1, 2, 3… (그림·따라 하기·연습 과제) |
| **사진 진단** | 찍은 사진을 올리면 밝기·대비·색온도·색조·선명도를 재고, 얼굴/발끝/수평선을 짚으면 5·8 구도와 기울기까지 판정. 몇 가지 질문으로 원인을 더 좁힌다. claude.ai 에서 열면 Claude 정밀 진단도 가능 |
| **촬영 직전** | 전신·상반신·거울샷·카페·풍경별 체크리스트 (렌즈 닦기 → 격자 → 높이 → 5·8 → 45° 빛 → 다다다) |
| **내 고민** | 한 번에 하나만. 해 보고 "나아졌어요 / 그대로예요 / 못 했어요". 그대로면 다음 원인으로 자동으로 넘어간다 |

### 에이전시와 연결

`내 고민` 탭 아래 **에이전시 기록**이 오늘 누른 결과를 자기계발 채널실 형식으로 만들어 준다.

```
---
결과물: 사진 연습 기록
태그: 사진, 기록
작성: 인생샷 처방전
---
```

복사해서 `~/agency/rooms/channel/YYYY-MM-DD_사진-연습-기록.md` 로 저장하면 오피스 맵 채널실에 나타난다.
"못 했어요"도 그대로 적힌다 (채널실 원칙: 못 한 것도 같이 보여준다).

### 저장

- claude.ai 에서 열면 기록이 **내 Claude 계정의 개인 공간**에 저장된다 (나만 보임, 다른 기기에서도 이어짐)
- 파일로 직접 열면 그 브라우저에만 저장된다
- 사진은 화면 안에서만 분석한다. **Claude 정밀 진단**을 누를 때만 Claude 에게 보낸다

## 아직 안 한 것

1. **데일리 브리핑 화면** — 비서가 정면 보고 브리핑하는 영상 촬영용 화면
2. 근무일/휴무일 **자동 판단** (지금은 `daily/오늘.md` 의 `근무:` 줄을 읽음)
3. 화면에서 만든 지시를 파일까지 자동 생성 (지금은 프롬프트 복사 방식)
4. 새로 만든 방은 부서에 자동으로 들어가지 않음
