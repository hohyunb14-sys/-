작업 목록

음성 인식 (STT)

리턴제로 키가 있으면 한국어 간투어("음", "어")까지 잘 받아써서 정확도가 높습니다. developers.rtzr.ai에서 무료로 발급받을 수 있습니다. 키가 없으면 내 컴퓨터의 Whisper를 씁니다(pip install faster-whisper 필요, GPU 없으면 느림). 환경변수 RTZR_CLIENT_ID, RTZR_CLIENT_SECRET가 있으면 그 값이 우선합니다.

AI 검토 (Claude)

전사문(텍스트)만 Claude에 보내서 규칙이 놓친 말실수·다시 말한 구간을 찾고, 규칙 컷 중 이상한 것을 표시합니다. 음성 파일은 보내지 않습니다. pip install anthropic과 API 키가 필요하며, 환경변수 ANTHROPIC_API_KEY가 있으면 그 값이 우선합니다.

탐지 기준 (기본값)

작업마다 검토 화면에서 다시 조정할 수 있습니다.

작업 폴더: — 키는 이 폴더의 settings.json 에 평문으로 저장됩니다. 내 컴퓨터에서만 쓰는 도구라는 전제입니다.
