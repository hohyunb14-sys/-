# 조직도

지시는 위에서 아래로만 흐른다.
비서는 항상 **실장**에게만 하달하고, 실장이 아래로 위임한다.

```
대표 (방호현)
└ 비서 (에이전트 비서)
   ├ 장례 콘텐츠실
   ├ 건강관리실
   └ 자기계발 채널실
```

## 사람

방 칸에는 `rooms/` 밑의 폴더 이름을 적는다. 한 방에 최대 3명 (실장 / 과장 / 대리).

| 이름 | 직급 | 역할 | 방 |
|---|---|---|---|
| 서진 | 실장 | 콘텐츠 작가 | funeral-content |
| 한결 | 실장 | 건강 코치 | health |
| 다온 | 실장 | 채널 PD | channel |
