# 권역모임 지원금 활용 건의 — 구글 익명투표

정성용 팀장님 지원금(50만원, '권역모임회 일동' 명의)에 대해 **익명으로 동의/거절**을 받는 구글 설문입니다.
**거절이 1표라도 있으면** 모임 지원금 대신 자율 모금으로 진행합니다.

---

## 방법 A. 스크립트로 자동 생성 (PC, 1분) — 추천

1. PC에서 <https://script.google.com> 접속 → **[새 프로젝트]**
2. 원래 있던 코드를 모두 지우고 [`create-vote-form.gs`](create-vote-form.gs) 내용을 **전부 복사해서 붙여넣기** → 저장(Ctrl+S)
3. 위쪽 함수 선택 칸에서 **`createVoteForm`** 선택 → **[실행]**
4. 처음 한 번 권한 승인 창이 뜹니다
   → 내 구글 계정 선택 → **[고급]** → **[(프로젝트 이름)(으)로 이동]** → **[허용]**
   (내가 만든 스크립트라 "확인되지 않은 앱" 경고가 뜨는 게 정상입니다)
5. 아래 **[실행 로그]** 에 나온 `📨 응답 링크` (forms.gle/…) 를 단톡방에 공유

마감 기한을 설문에 표시하고 싶으면 스크립트 맨 위 `deadline: ''` 칸에 예) `'11월 12일(목) 18시까지'` 를 넣고 실행하세요.

**마감 후**
- `closeVote` 실행 → 응답 받기 종료
- `checkResult` 실행 → 실행 로그에 `총 응답 · 동의 · 거절` 수와 결론(지원금 전달 / 자율 모금)이 나옵니다

---

## 방법 B. 직접 만들기 (휴대폰도 가능)

<https://forms.google.com> → **[+ 새 양식]**

**제목**: `권역모임 지원금 활용 건의 — 익명 의견 수렴`

**설명** (그대로 붙여넣기)
```
권역모임 지원금 활용방안 건의 내용입니다.

현재 정성용 팀장님 자녀 진료 문제로 행사 순번 진입이 어려운 상황입니다.
모임 참여 중인 팀원분들께서 소정의 금액을 지원해 드리면 어떻겠냐는 건의를 주셔서, 모임 지원금 50만원을 '권역모임회 일동' 명의로 전달하는 방안을 생각하고 있습니다.

다만 모임의 원칙상 지원금 용도와 맞지 않을 수 있어,
▶ 한 분이라도 거절 의사가 있으시면 모임 지원금은 사용하지 않고, 별도로 자율적으로 모아서 전달하겠습니다.

🔒 이 투표는 익명입니다. 이메일·이름 등 응답자 정보는 수집되지 않으며, 만든 사람도 누가 어떻게 응답했는지 알 수 없습니다. 편하게 의견 주세요.
```

**질문 1** — 객관식, **필수** 켜기
- 질문: `모임 지원금 50만원을 '권역모임회 일동' 명의로 정성용 팀장님께 전달하는 것에 대해 의견을 선택해 주세요.`
- 보기 1: `동의합니다 — 모임 지원금으로 전달`
- 보기 2: `거절합니다 — 모임 지원금 사용 반대 (자율 모금으로 진행)`

**질문 2** — 장문형, 필수 끄기
- 질문: `기타 의견 (선택)`

**⚙️ 설정 탭 — 익명이 되려면 반드시 확인**

| 항목 | 값 | 이유 |
|---|---|---|
| 응답 → 이메일 주소 수집 | **수집 안함** | 켜면 누가 응답했는지 보입니다 |
| 응답 → 응답 횟수 1회로 제한 | **끔** | 켜면 구글 로그인이 필요해 익명으로 느껴지지 않습니다 |
| 응답 → 응답 수정 허용 | 끔 | |
| 프레젠테이션 → 결과 요약 보기 | 끔 | 결과는 만든 사람이 단톡방에 공유 |

마지막으로 오른쪽 위 **[게시]** → 응답자 **"링크가 있는 모든 사용자"** 확인 → **[링크 복사]** (🔗, URL 단축 체크)

> 응답 횟수 제한을 끄면 같은 사람이 여러 번 낼 수는 있지만,
> "거절 1표 이상이면 자율 모금"이라는 규칙이라 결론은 바뀌지 않습니다.
