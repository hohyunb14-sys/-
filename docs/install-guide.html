방호현 에이전시 설치

터미널을 처음 열어보셔도 됩니다. 아래 순서대로 복사해서 붙여넣기만 하면 끝납니다. 각 단계마다 “이렇게 나오면 성공”을 붙여놨으니 화면과 비교하면서 가시면 됩니다.

이 설치는 대표님 맥의 어떤 파일도 지우거나 덮어쓰지 않습니다. 새 폴더 ~/agency 를 만들고 거기에 없는 파일만 채웁니다. 이미 있는 파일은 건드리지 않습니다.
01

터미널 열기

⌘ + Space 를 누르고 터미널이라고 친 다음 Enter. 검은(또는 흰) 창이 뜹니다.

맨 끝에 커서가 깜빡이는 줄이 입력하는 자리입니다. 여기에 붙여넣고 Enter 를 치면 실행됩니다.

붙여넣기는 ⌘ + V. 아래 명령어 블록의 복사 버튼을 누르면 클립보드에 들어갑니다.
02

파일 받기

두 가지 방법 중 하나만 하시면 됩니다.

방법 A — 터미널로 받기 추천

한 번에 됩니다. 아래를 복사해서 붙여넣으세요.

터미널
$ cd ~
$ git clone -b claude/animated-room-management-a8hlc4 https://github.com/hohyunb14-sys/-.git agency-app
$ cd agency-app

GitHub 아이디와 비밀번호를 물어보면, 브라우저에서 GitHub 에 로그인된 계정으로 진행하시면 됩니다.

방법 B — 브라우저로 받기

  1. 저장소 페이지를 엽니다 (GitHub 로그인 필요).
  2. 초록색 Code 버튼 → Download ZIP.
  3. 다운로드 폴더에서 받은 zip 을 더블클릭해 압축을 풉니다.
  4. 터미널에 cd 를 치고 띄어쓰기 한 칸 다음, 압축 푼 폴더를 터미널 창 위로 드래그하면 경로가 자동으로 들어갑니다. Enter.

어느 쪽이든, 제대로 왔는지 확인합니다.

터미널
$ ls
이렇게 나오면 성공 
README.md   agency   install.sh   office-map.html   scan.mjs
안 될 때

No such file or directory — 폴더 위치가 다릅니다. cd 를 치고 폴더를 터미널로 드래그하는 방법(방법 B의 4번)을 쓰세요. 제일 확실합니다.

git: command not found — 창이 하나 뜨면서 개발자 도구를 설치할지 물어봅니다. 설치를 누르고 끝난 뒤 다시 시도하세요. (몇 분 걸립니다)

03

설치하기

이 한 줄이 ~/agency 폴더를 만들고, 방과 규칙 파일을 넣고, 화면에 반영까지 합니다.

터미널
$ bash install.sh
이렇게 나오면 성공 
  방호현 에이전시 설치
  ─────────────────────────────────
  자료 폴더 : /Users/…/agency
  화면 파일 : /Users/…/agency-app/office-map.html

  들어 있는 것:
    ~/agency/CLAUDE.md
    ~/agency/team.md
    ~/agency/rooms/funeral-content/CLAUDE.md
    …

읽음  /Users/…/agency
  방      3개 — 장례 콘텐츠실(1), 건강관리실(1), 자기계발 채널실(1)
  사람    3명
  토큰    …

  다 됐습니다. 이 줄을 복사해서 실행하세요:

      open "/Users/…/agency-app/office-map.html"
마지막에 open "…" 로 시작하는 줄이 나옵니다. 그 줄을 그대로 복사해 두세요. 다음 단계에서 씁니다.
“Node.js 가 없어…” 라고 나오면

폴더는 정상적으로 만들어졌습니다. 화면에 반영하는 부분만 Node.js 라는 프로그램이 필요합니다. 둘 중 편한 쪽으로 설치하세요.

  1. nodejs.org 접속 → 큰 LTS 버튼 클릭 → 받은 .pkg 더블클릭 → 계속 누르기
  2. 또는 터미널에서 brew install node (Homebrew 를 이미 쓰고 계시면)

설치가 끝나면 터미널을 완전히 닫고 새로 연 다음, 다시 2단계의 cd 와 3단계의 bash install.sh 를 하세요.

이미 설치한 적이 있는데 다시 돌려도 되나요

네. 몇 번을 돌려도 이미 있는 파일은 그대로 둡니다. 직접 쓰신 내용이 사라지지 않습니다. 없는 파일만 채웁니다.

04

화면 열기

3단계 마지막에 나온 open "…" 줄을 붙여넣고 Enter. 기본 브라우저에 사무실이 뜹니다.

터미널 · 3단계에서 나온 줄을 그대로
$ open office-map.html
이렇게 나오면 성공 
화면 왼쪽 위에 초록 점과 함께
  ● 실데이터 · /Users/…/agency · 03:31 스캔
이 뜹니다.
초록 배지가 안 보이고 아래쪽에 지시 버튼들이 잔뜩 보이면 데모 모드입니다. 실제 폴더를 못 읽었다는 뜻이니, 터미널에서 bash install.sh 를 한 번 더 돌리고 브라우저를 새로고침(⌘+R)하세요.

방을 클릭하면 그 방의 자료 연관도가 열립니다. 동그라미를 누르면 여기서 파생할 수 있는 일이 나옵니다.

05

Claude Code 연결

여기까지는 보는 화면입니다. 실제로 글을 쓰고 파일을 만드는 건 Claude Code 가 합니다. 먼저 깔려 있는지 확인합니다.

터미널
$ claude --version
이렇게 나오면 이미 있음 
2.1.42 (Claude Code)

command not found 가 나오면 아래로 설치합니다.

터미널 · Claude Code 설치
$ curl -fsSL https://claude.ai/install.sh | bash

설치 후 터미널을 새로 열고, 자료 폴더에서 실행합니다.

터미널
$ cd ~/agency
$ claude

처음이면 브라우저가 열리면서 로그인하라고 합니다. 지금 쓰시는 계정으로 로그인하면 됩니다.

첫 인사로 이걸 쳐보세요
CLAUDE.md 읽고 이 폴더가 뭐 하는 곳인지 설명해줘
방 구조와 각 방의 원칙을 읽고 정리해줍니다. 제대로 붙었는지 확인하는 가장 빠른 방법입니다.

매일 쓰는 법

설치는 한 번이면 끝입니다. 이후에는 이 세 가지만 오갑니다.

언제무엇을
일을 시킬 때 Claude Code — cd ~/agency && claude
대화하면서 결과물을 방 폴더에 파일로 남깁니다.
화면에 반영 스캔 — node scan.mjs (agency-app 폴더에서)
폴더를 읽어 화면 데이터를 새로 씁니다. 읽기만 합니다.
볼 때 · 지시를 짤 때 화면 — open office-map.html
방을 눌러 파생을 고르면 그 방 원칙이 들어간 프롬프트가 나옵니다. 복사해서 Claude Code 에 붙여넣으세요.
스캔이 귀찮으면 터미널 창 하나를 이렇게 띄워두세요. 30초마다 알아서 갱신합니다. 끄려면 Ctrl+C.
터미널 · agency-app 폴더에서
$ while true; do node scan.mjs >/dev/null; sleep 30; done

설치 끝나면 제일 먼저 할 것

방 세 개의 원칙 파일을 대표님 말로 고치는 것입니다. 여기 적은 문장이 그대로 제 작업 규칙이 됩니다.

터미널 · 텍스트편집기로 열기
$ open -e ~/agency/rooms/funeral-content/CLAUDE.md

지금은 제가 임시로 이렇게 적어놨습니다.

rooms/funeral-content/CLAUDE.md 
- 모토: 정보보다 태도
- 원칙: 유가족이 지금 당장 쓸 수 있는 말만 남긴다.
- 안 하는 것: 자극적인 제목, 통계 나열, 과장된 감정 연출
- 말투: 담담하고 낮은 톤

고치고 저장한 뒤 node scan.mjs 를 다시 돌리면 화면의 방 설명도 같이 바뀝니다. ~/agency/team.md 표에 한 줄 추가하면 새 직원이 화면에 나타납니다.
